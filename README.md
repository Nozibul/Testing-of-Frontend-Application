
## 📚 What's Inside

This repository covers different aspects of software testing with practical examples and implementations.

### Unit Testing & Integration Testing

Understanding the fundamentals of testing individual components and their interactions.

**Component Testing**
- Testing isolated React components
- Mocking dependencies and props
- Snapshot testing for UI consistency

**Jest & JS DOM**
- JavaScript testing framework fundamentals
- DOM manipulation testing
- Asynchronous code testing
- Mock functions and spies

**Testing Library / React Testing Library**
- User-centric testing approach
- Querying elements effectively
- Testing user interactions
- Accessibility-focused testing

### Automation Testing

Exploring end-to-end testing and browser automation.

**E2E Test Cases**
- User journey testing
- Cross-browser compatibility
- Performance testing scenarios

**Tools & Frameworks**
- **Puppeteer**: Headless Chrome automation
- **Cypress**: Modern web testing framework
- **Selenium**: Cross-browser automation

## Getting Started

```bash
# Clone the repository
git clone [https://github.com/Nozibul/Testing-of-Frontend-Application.git]

# Install dependencies
npm install

# Run tests
npm test

```
